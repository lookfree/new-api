## 七、下一步建议

按价值排序：

1. **买域名并启动 ICP 备案。** 关键路径，其余大半事项都排在它后面。
2. **补服务条款与隐私政策正文。** 上线硬门槛，且不依赖任何技术进度，现在就能做。
3. **余额预警邮件。** 用户余额耗尽直接断服，这是运营事故。
4. **模型详情的「试一下」入口。** 用户能直接感知的缺失，工作量不大。
5. **邀请页补「提现到余额」按钮。** 同上。
6. **钱包页支付区域收敛。** 等支付方案定了再动。
